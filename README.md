# Björn desktop releases

This repo holds the download files for the Björn desktop app. There is no source code here, only the built app.

Björn is a language learning app that builds your lessons around whatever you actually care about, so you practise real conversations instead of naming fruit. It covers German, Swedish, French, Spanish, Italian, Portuguese and English.

- Website: https://www.heybjorn.com
- Use it in your browser: https://app.heybjorn.com
- Questions: hey@heybjorn.com

## Download

Grab the newest files from the [latest release](../../releases/latest).

- Mac with Apple Silicon (M1 or newer): `Bjorn-mac-arm64.dmg`
- Mac with Intel: `Bjorn-mac-x64.dmg`
- Windows: not out yet, it is being worked on

Not sure which Mac you have? Click the Apple menu, then About This Mac. If the chip says Apple M1, M2, M3 or M4, you want the Apple Silicon file.

## Install on Mac

1. Open the `.dmg` file you downloaded.
2. Drag Björn into your Applications folder.
3. Open it from Applications, not from the little disk image window. Apps run from the disk image cannot update themselves later.
4. Sign in with the same account you use on heybjorn.com. If you do not have one yet, you can make one for free at https://app.heybjorn.com
5. Say yes to the microphone prompt the first time you start a conversation. The mic is only on while you are speaking.

The app is signed and notarised by Apple, so it opens without any security warnings.

## Updates

- The app checks for new versions by itself and installs them quietly in the background.
- The next time you open Björn after an update is ready, you are already on the new version.
- You only ever need to download from this page once.

## What are the .zip files?

Those are for the app's own updater, not for people. If you are installing Björn by hand, use the `.dmg` file.

## Older versions

Every release stays up, so you can always go back to an earlier version from the [releases page](../../releases) if you need to.
